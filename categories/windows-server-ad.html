Installation / exploitation d’un Windows Server avec Active Directory

Contexte

Dans le cadre de la mise à disposition d’un service informatique, j’ai installé et configuré un serveur Windows Server avec le rôle Active Directory Domain Services. L’objectif était de centraliser l’authentification des utilisateurs, la gestion des postes et l’administration des ressources du domaine.

Objectifs

  • Installer un serveur Windows Server
  • Configurer l’adresse IP, le nom du serveur et les paramètres réseau
  • Installer le rôle Active Directory Domain Services
  • Créer un domaine Active Directory
  • Configurer le service DNS associé au domaine
  • Créer et organiser les utilisateurs, groupes et unités d’organisation
  • Intégrer des postes clients au domaine
  • Vérifier le bon fonctionnement de l’authentification centralisée

Environnement technique

Windows Server Active Directory AD DS DNS Domaine Utilisateurs Groupes GPO

Travaux réalisés

Installation du serveur

Installation de Windows Server sur une machine physique ou virtuelle, configuration initiale du système, renommage du serveur et définition d’une adresse IP fixe afin de garantir la stabilité du service.

Installation du rôle AD DS

Ajout du rôle Active Directory Domain Services depuis le gestionnaire de serveur, puis promotion du serveur en contrôleur de domaine.

Création du domaine

Création d’un nouveau domaine Active Directory permettant de centraliser la gestion des comptes utilisateurs, des groupes, des ordinateurs et des stratégies de sécurité.

Configuration DNS

Mise en place du service DNS lié à Active Directory afin de permettre la résolution des noms internes et le bon fonctionnement des services du domaine.

Gestion des comptes

Création d’utilisateurs, de groupes et d’unités d’organisation afin de structurer l’annuaire selon les besoins de l’organisation.

Intégration des postes clients

Ajout de postes Windows au domaine Active Directory, puis test de connexion avec des comptes utilisateurs du domaine.

Fonctionnalités mises en place

  • Installation et configuration d’un Windows Server
  • Promotion du serveur en contrôleur de domaine
  • Création d’un domaine Active Directory
  • Configuration du service DNS
  • Création d’utilisateurs et de groupes
  • Organisation de l’annuaire avec des unités d’organisation
  • Jonction de postes clients au domaine
  • Authentification centralisée des utilisateurs
  • Préparation à la mise en place de stratégies de groupe

Résultats obtenus

Service opérationnel

  • Serveur Windows installé et configuré
  • Contrôleur de domaine fonctionnel
  • Domaine Active Directory créé
  • Service DNS opérationnel
  • Utilisateurs et groupes créés
  • Postes clients intégrés au domaine
  • Authentification des utilisateurs validée

Impact

La mise en place d’Active Directory permet de centraliser l’administration du système d’information. Elle facilite la gestion des utilisateurs, des droits d’accès, des postes clients et améliore la sécurité globale de l’infrastructure.

Compétences mobilisées

  • Mise à disposition d’un service informatique
  • Administration d’un serveur Windows
  • Gestion d’un annuaire Active Directory
  • Configuration réseau et DNS
  • Gestion des utilisateurs, groupes et ordinateurs
  • Sécurisation des accès au système d’information
  • Tests et validation d’un service d’infrastructure

Bilan personnel

Cette réalisation m’a permis de mieux comprendre le fonctionnement d’un annuaire Active Directory et son importance dans une infrastructure professionnelle. J’ai appris à installer un contrôleur de domaine, à gérer les utilisateurs et à intégrer des postes clients dans un environnement centralisé.
